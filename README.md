# splitmime

Split structured JSON mime payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/splitmime/

## Install / run

```bash
git clone https://github.com/theworker02/splitmime.git
cd splitmime
node src/cli.js
node --test
```
